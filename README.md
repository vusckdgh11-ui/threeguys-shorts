ThreeGuys Shorts
================

쓰리가이즈 특수청소용 Windows 쇼츠 자동 제작 프로그램.

사용 흐름
1. 영상 여러 개 추가
2. 현장 설명 입력
3. 40/50/60초 선택 후 “1. 영상 분석 + 쓸 장면 자동 선택”
4. 선택된 타임라인 확인
5. “2. 타임라인 기반 대본 만들기”
6. Windows TTS 음성 선택/미리듣기
7. 필요하면 로고/이미지 추가 및 위치/크기 설정
8. “3. MP4 자동 제작”

중요
- 대본은 영상 분석/타임라인 생성 전에는 만들 수 없도록 설계되어 있습니다.
- 기본 장면 분석은 로컬 영상의 움직임/선명도/변화량을 이용한 자동 선택입니다.
- 사람처럼 ‘칼, 혈흔, 침대, 약품’의 의미를 완벽히 이해하는 AI 장면 인식은 별도 비전 AI 모델/API가 필요합니다.
- Windows 기본 SAPI TTS를 사용하므로 별도 TTS API 비용이 없습니다.
- 최종 출력은 H.264 MP4 세로 1080x1920입니다.
