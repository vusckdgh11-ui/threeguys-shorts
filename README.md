# ThreeGuys Shorts V3 SyncFix

이번 버전 핵심 수정:
- 영상 컷 1개 = 대본 1줄 = TTS 1개 구조로 변경
- TTS 실제 길이를 측정해 각 영상 컷 길이와 자막 시간을 맞춤
- 미리보기 영역을 가운데 고정 9:16 패널로 분리해 UI가 밀리지 않도록 변경
- 로고 선택 후 모서리 핸들을 마우스로 드래그해 크기 조절, 본체 드래그로 이동
- TTS 공급자 분리: Windows 기본 음성 / Google 무료(gTTS) / Typecast
- Typecast API 키는 Windows DPAPI로 암호화해 로컬 설정에 저장
- 자막 스타일 선택 및 위치/크기 조절 유지

## 사용 순서

1. 여러 원본 영상을 추가하고 40/50/60초 편집 목표를 선택합니다.
2. 분석 후 컷을 확인합니다. 선택 컷의 시작/끝을 수정하거나 불필요한 컷을 삭제할 수 있습니다.
3. 타임라인 확정 후 대본을 만듭니다. 한 줄이 한 컷이며, 모든 컷에 빈 줄 없이 대본이 있어야 합니다.
4. Windows / Google(gTTS) / Typecast 음성을 선택하고 미리듣습니다.
5. 로고나 이미지를 추가하고 본체 이동·모서리 리사이즈, 자막 위치·크기, 광고 배너·효과를 설정합니다.
6. MP4 제작을 누릅니다. 각 TTS의 실제 길이와 짧은 무음을 합쳐 30fps 단위로 컷·자막을 맞춥니다.

## SyncFix 수정

- 선택한 원본 시작~끝 구간만 사용합니다. 긴 음성 때문에 선택하지 않은 다음 장면이 섞이지 않습니다.
- 영상 재생 시간을 음성에 맞추고 부족한 마지막 프레임은 유지합니다. 음성은 무음 패딩 후 명시적 컷 길이로 자릅니다.
- 컷별 PCM 음성을 합친 후 한 번 AAC로 인코딩하여 컷마다 생기는 인코더 지연을 피합니다.
- FFmpeg `-shortest`를 사용하지 않습니다. 최종 전체 길이를 명시하고 저장 전 실제 출력 길이를 확인합니다.
- 한 번에 한 컷을 처리하여 많은 원본을 동시에 열 때의 메모리·명령 길이 문제를 줄입니다.
- 원본 덮어쓰기를 차단하고 성공한 완성 파일만 출력 위치에 반영합니다.
- 로고 좌표 오류, 모서리 리사이즈, 숫자 입력과 미리보기 연결을 수정했습니다.
- Windows 작업 스레드의 COM 초기화와 자원 해제를 추가했습니다.
- Typecast 목록과 음성 미리듣기를 백그라운드에서 처리합니다.
- 구버전의 평문 Typecast 설정 항목을 삭제합니다. 키는 소스·로그에 넣지 않고 Windows DPAPI 암호화 값만 로컬 설정에 저장합니다. 암호화가 불가능한 환경에서는 저장하지 않습니다.

## 실제 한계

- 장면 선택은 밝기·선명도·움직임을 점수화한 휴리스틱입니다. 혈흔, 약품, 작업 단계 등의 의미를 인식하지 않습니다. 검은 화면도 점수 기준으로만 거르므로 사람이 컷을 확인해야 합니다.
- 대본은 설명과 컷 순서에 맞춘 템플릿 초안입니다. 영상에서 실제 확인되지 않은 내용을 말할 수 있으므로 각 컷과 대조해 수정하세요.
- 40/50/60초는 **원본 편집 타임라인 목표**입니다. 유효 후보가 부족하면 짧아지며 같은 장면을 복제해 채우지 않습니다. 최종 MP4는 실제 TTS 길이에 맞추므로 목표와 달라질 수 있습니다.
- 가운데 미리보기는 컷의 정지 화면을 넘겨보는 편집 화면입니다. 실시간 완성 영상·음성 재생이나 최종 자막 스타일의 정확한 재현은 아닙니다. 완성 MP4로 최종 확인하세요.
- 로고/이미지는 한 개이며 모서리에서 종횡비를 유지해 크기를 조절합니다.
- Google과 Typecast는 인터넷이 필요합니다. Typecast는 별도 API 키와 사용량이 필요하며 공급자의 이용 조건이 적용됩니다.

## 빌드·검증

`main` 반영 시 Actions에서 Windows EXE를 빌드합니다. 타임라인 회귀 검사, Windows 음성 합성, 실제 H.264 1080×1920 렌더를 검사하고, FFmpeg·Windows 모듈을 포함한 **완성 EXE 자체**도 `--self-test`로 실행합니다.

성공한 Actions의 `ThreeGuysShorts-Windows` artifact에 EXE, SHA256, 소스·EXE 렌더 검증 보고서가 포함됩니다.

로컬 개발: `pip install -r requirements.txt`, `python app.py`.
검증: `python -m unittest -v test_sync`, `python smoke_test.py smoke-source.json`.

Typecast API 형식 참고: https://typecast.ai/docs/api-reference/text-to-speech/text-to-speech
