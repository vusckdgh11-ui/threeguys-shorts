# ThreeGuys Shorts V4.1 — 현장 이야기 AI 편집

## V4.1 수정 사항

- 현장 설명을 여러 줄로 입력할 수 있습니다. 설명에서 명시된 사실과 이야기 주제를 먼저 정리한 뒤, 설명의 사실과 컷의 시각 정보를 함께 써서 대본을 만듭니다. 설명을 그대로 복사한 결과는 다시 작성합니다.
- 예를 들어 설명에 생존 사실이 명시돼 있으면 “네. 다행히 살아 계십니다.” 같은 문맥상 안도감을 주는 문장을 사용할 수 있습니다. “자살시도”라는 말만으로 생존·사망을 추정하지 않습니다. 대본의 자연스러움은 실제 모델 응답에 따라 달라집니다.
- AI 타임라인은 업로드 순서나 파일명 순서가 아닌 장면 내용과 이야기 흐름으로 구성하도록 지시합니다. 선택된 컷은 0.25초 간격 프레임으로 다시 확인해 시작·끝을 좁힌 뒤 대본을 작성합니다. 샘플 사이 사건의 정확한 시점까지 보장하는 방식은 아닙니다.
- 타임라인 표에 원본 시작/끝과 출력 시작/끝을 표시합니다. 출력 시간은 TTS 생성 전에는 예상치이며, 생성 후 실제 음성 길이 기준으로 갱신됩니다. 자막도 같은 시간표를 사용합니다.
- 로고 네 모서리에 화면상 고정 크기의 조절점을 추가했습니다. 투명 이미지도 모서리를 드래그해 종횡비를 유지하며 크기를 바꿀 수 있고, 본체를 드래그하면 이동합니다.
- 초기 분석 프레임 한도 외에 선택 컷 정밀 확인·대본 재확인 프레임이 추가 전송됩니다. 현장 설명 정리와 원문 복사 재작성에도 API 호출이 추가될 수 있습니다.

영상 내용을 인식하는 OpenAI Vision API를 연결했습니다. V3의 밝기 점수 컷 선택 및 고정 문장 템플릿은 제거했습니다.

## 사용 방법

1. 원본 영상을 여러 개 추가하고 현장 설명과 편집 목표 40/50/60초를 선택합니다.
2. **영상 인식 AI 연결**에 OpenAI API 키를 입력합니다. Typecast 키와 별개입니다. 기본 모델은 gpt-4.1-mini이며 지원되는 이미지 입력·Structured Outputs 모델 이름으로 변경할 수 있습니다.
3. Windows / Google(gTTS) / Typecast 음성과 로고·자막 옵션을 선택합니다.
4. **AI 영상 인식부터 MP4까지 한 번에**를 누르고 출력 위치를 선택합니다.

중간 결과를 먼저 검토하려면 **AI 영상 인식 + 컷·대본 만들기**를 누르세요. 표에 인식 내용, 선택 이유, 대본이 표시됩니다. 대본 셀의 도움말에는 시각적 근거가 표시됩니다. 컷 범위를 수정하면 해당 대본은 무효화되며, **현재 컷을 AI가 다시 보고 대본 작성**으로 다시 생성합니다. 사용자가 대본을 직접 수정할 수도 있습니다.

## 실제 처리 흐름

- 전체 원본에서 0.5 / 1 / 2초 간격으로 실제 프레임을 추출합니다. 밝기 점수로 일부 영상만 먼저 고르지 않습니다.
- 8초 창별로 시간 표시 프레임을 AI에 전송하여 보이는 내용, 작업 동작, 단계, 사용 가치, 근거 시점을 분석합니다.
- AI가 전체 장면 목록에서 중복과 작업 흐름을 고려해 필요한 컷과 순서를 정합니다.
- 확정된 각 컷의 앞·중간·끝 프레임을 AI에 다시 보여주고 그 컷에 근거한 대본을 생성합니다.
- 한 컷 = 한 대본 = 한 TTS로 합성합니다. 실제 TTS 길이에 영상과 자막을 맞추고 H.264 1080×1920 MP4로 저장합니다.
- API 실패, 거절, 빈 결과, 잘못된 시간·장면 번호·대본 대응은 오류로 중단합니다. 휴리스틱이나 고정 대본으로 대체하지 않습니다.

## 키와 외부 전송

분석 버튼을 누르면 선택한 영상의 프레임과 설명이 OpenAI API로 전송되고 별도 API 사용료가 발생합니다. ChatGPT/Codex 로그인만으로 동작하는 기능은 아닙니다. 키는 프로그램에 직접 입력하며 소스나 GitHub에 넣지 않습니다. Windows DPAPI로 암호화한 값만 로컬 설정에 저장합니다. 암호화가 안 되면 현재 실행 메모리에서만 사용하고 화면에 알립니다. AI 키 저장 삭제 버튼으로 저장 값을 지울 수 있습니다. 요청은 store=false로 보내며 API 응답의 원문·키·프레임을 로그에 기록하지 않습니다.

## 한계와 검증 범위

- 연속 영상 파일 자체를 입력하는 모델이 아니라 **시간별 프레임을 보는 시각 AI**입니다. 원본 음성은 분석하지 않고 짧은 동작·샘플 사이 장면은 놓칠 수 있습니다. 정밀 모드는 0.5초 간격입니다.
- AI 설명과 대본에는 오인식이 있을 수 있습니다. 확인되지 않은 혈흔, 냄새, 사망 원인, 약품명, 작업 결과를 단정하지 않도록 지시하지만 결과 검토는 필요합니다.
- 한 번에 예상 1200프레임까지 처리합니다. 초과 시 전송 전에 중단하며 영상을 나누거나 간격을 늘릴 수 있습니다.
- 유효 컷이 부족하면 목표보다 짧습니다. 목표 40/50/60초는 편집 타임라인 길이이며 최종 길이는 실제 음성 길이에 따라 바뀝니다.
- 가운데 미리보기는 컷별 정지 화면입니다. 최종 영상 재생은 생성한 MP4에서 확인하세요.
- AI API 계약, 실제 프레임 추출, 범위·중복·대본 대응, 한 번에 제작 연결은 자동 테스트의 모의 AI 응답으로 검증합니다. **실제 AI 서비스의 인식 품질은 사용자 API 키와 실제 영상으로 별도 확인해야 합니다.**
- Windows 음성, FFmpeg 포함 여부, 자막·로고·싱크·암호화는 Actions에서 소스와 완성 EXE로 검사합니다.

## 빌드

main 반영 시 Windows EXE를 빌드하고 완성 EXE 자체를 실행해 MP4를 생성합니다. ThreeGuysShorts-Windows artifact에 EXE와 SHA256, 검증 보고서가 포함됩니다.

개발: pip install -r requirements.txt 후 python app.py
검사: python -m unittest -v test_sync test_ai 및 python smoke_test.py smoke-source.json

공식 API 근거:
- https://developers.openai.com/api/docs/guides/images-vision
- https://developers.openai.com/api/docs/guides/structured-outputs
- https://developers.openai.com/api/docs/models/gpt-4.1-mini
